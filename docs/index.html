Install

Requires Go ≥ 1.25. On Linux and macOS a C compiler is needed too (Wails links WebView via cgo); Windows is pure Go.

Windows / macOS

go install -tags production github.com/ebdonato/dumd@latest

Linux

Build deps: libgtk-3-dev libwebkit2gtk-4.1-dev

go install -tags "production webkit2_41" github.com/ebdonato/dumd@latest
To install a specific version, replace @latest with a tag, e.g. @v1.3.2. Prefer a prebuilt binary? Grab one from the latest release for Windows, macOS (ARM/Intel), or Linux.

Usage

Open any Markdown file straight from your terminal.

dumd README.md

Launch it without a file argument to see a welcome screen with usage instructions. Relative .md links open in a new DuMD window; external links open in your default browser.

Why DuMD

Built for people who just want to read a file — nothing more.

🪶 Featherweight

Binary under 18 MB, idle RAM under 60 MB.

⌨️ Keyboard-first

Vim-style scrolling, spacebar page navigation, single-key theme switching.

🎨 Three themes

Light, Dark, and Sepia, persisted across sessions.

📦 Zero dependencies

No Node.js, no Python, no installers — just one executable.

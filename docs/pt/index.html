DuMD

Um visualizador de Markdown para desktop, ultraminimalista e controlado pelo teclado.

↓ Última Versão Ver no GitHub

Windows · macOS · Linux — binário único, sem dependências de runtime

Três temas de leitura

Claro, Escuro e Sépia — troque a qualquer momento com uma única tecla.

Claro — Limpo e nítido para leitura durante o dia

Instalação

Requer Go ≥ 1.25. No Linux e macOS também é necessário um compilador C (o Wails usa cgo para o WebView); no Windows é Go puro.

Windows / macOS

go install -tags production github.com/ebdonato/dumd@latest

Linux

Dependências de build: libgtk-3-dev libwebkit2gtk-4.1-dev

go install -tags "production webkit2_41" github.com/ebdonato/dumd@latest
Para instalar uma versão específica, substitua @latest por uma tag, por exemplo @v1.3.2. Prefere um binário pronto? Baixe um na última versão para Windows, macOS (ARM/Intel) ou Linux.

Uso

Abra qualquer arquivo Markdown diretamente do terminal.

dumd README.md

Inicie sem argumento de arquivo para ver uma tela de boas-vindas com instruções de uso. Links relativos para .md abrem em uma nova janela do DuMD; links externos abrem no navegador padrão.

Por que o DuMD

Feito para quem só quer ler um arquivo — nada mais.

🪶 Leve

Binário com menos de 18 MB, RAM ociosa abaixo de 60 MB.

⌨️ Foco no teclado

Rolagem estilo Vim, navegação por página com a barra de espaço, troca de tema com uma tecla.

🎨 Três temas

Claro, Escuro e Sépia, salvos entre sessões.

📦 Zero dependências

Sem Node.js, sem Python, sem instaladores — apenas um executável.
